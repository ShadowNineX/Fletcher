# Fletcher

Fletcher compiles Go-style programs into playable Logic Arrows Levels. Write native arrow circuits, scripted routines, and hand-placed tile layouts in the same typed language.

## Learn Fletcher

- [Getting started](docs/language/getting-started.md) walks through installing the compiler, building three small maps, and opening them in Logic Arrows.
- [Language reference](docs/language.md) covers the syntax, types, functions, packages, map declarations, and built-in functions.
- [Logic Arrows target](docs/logic-arrows.md) explains physical layout, timing, and Level files.

## Examples

- [Half Adder](examples/half-adder.flt) builds physical gates.
- [Counter](examples/counter.flt) updates a register in a script.
- [Hybrid Indicator](examples/hybrid.flt) connects native signals to a script and back.
- [Hello Screen](examples/hello-screen/main.flt) draws text and shapes.
